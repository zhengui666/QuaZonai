# Archive preparation dependency notices

These texts accompany the 16 registry package versions added for optional offline archive preparation. Build-time packages are included. They do not constitute an inventory or audit of every QuaZonai dependency.

All license texts below are unchanged upstream bytes. Identical texts are stored once and linked from every applicable package. Both alternatives are retained for dual-licensed packages; encoding_rs also retains its WHATWG BSD text. No upstream license or copyright notice is replaced.

The exact package versions and archive checksums are in Cargo.lock. Original packaged texts were compared with the corresponding upstream Git blobs at each archive’s recorded .cargo_vcs_info.json revision. rc-zip 5.4.1 omits its license files from the crate archive, so its two texts are retained from that exact upstream revision. No separate NOTICE file was present in these crate archives or at those repository roots.

SHA256SUMS records the complete bytes of each retained text. The application-image build verifies that manifest in /usr/share/doc/quazonai/licenses/archive-source.
