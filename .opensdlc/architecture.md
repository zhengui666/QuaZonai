# 产品、领域与架构

<a id="product"></a>
## 产品边界

QuaZonai 是单人、本机、可扩展的无人值守研究工作台。核心链路是 idea → 研究试验与独立评价 → 策略／组合回测 → 目标交付与实盘／模拟盘观测。组合是研究结果的可选消费者，不是因子研究的前置条件。QZ 不持有券商账户、不发送金融订单；下游回执不等于实际成交。

前端保留研究、原子因子库、组合回测、目标与观测和设置入口；设置内集中模型设置、数据、数据插件、扩展和实例连接。状态、指标、表格和曲线直接表达事实，不展示原始 JSON、合同编辑器或解释性段落。

| [Rust contracts](../crates/contracts/src)、[domain](../crates/domain/src) | 科学内核所需的 Wire／Arrow 类型、数值、PIT、分区、费用与科学结果校验 |
| [Migrations](../migrations) | 保留已应用的 PostgreSQL 与原 Runtime SQLite 迁移；不重置历史数据库 |

应用通过 `nautilus.backtest` 连接研究／回测的远程 Nautilus，模拟盘与实盘通过各自 `connections` URL、账户和凭据引用连接；各用途不互相回退。新研究与子任务冻结远程连接，旧本地任务不静默迁移。模型与临时对象随 HTTP 请求传输，目录与冻结副本使用相同绝对路径的共享只读挂载；既有 PIT、修订和独立评估校验保持。部署与升级配置见[部署手册](../deploy/docker/README.md)。

非科学控制面不再依赖 Rust server、Store、Runtime 网关、integrations 或 Rust CLI。历史 PostgreSQL 记录通过只读适配访问，不伪造新的成功 Run／Attempt 或把旧执行身份改成 durable 身份。

官方 Pi Durable／pi-ai／Chord 负责模型与工具循环、Conversation、Submission、Task、原生持久化、重放、子任务、取消、等待、压缩和用量。QZ 不实现第二套任务数据库或调度器。NautilusTrader 负责目录、指标、撮合、共享资金模拟及权益；Clarabel 负责求解，Wasmi 负责有界模型执行，Arrow 保存原生列式结果。第三方实现只来自官方包或固定官方修订，不复制、修改或 fork。

<a id="contracts"></a>
## 身份、输入与结果

当前 API 为 `/api/v3`。原生科学合同仍在 Rust 源定义；历史生成快照不作为新的 HTTP 服务实现，也不手工改写生成文件。原始请求、`requestId`、原生 Conversation／Submission／Task ID、试验来源与结果关联保持不变。相同身份与正文重放原回执，改变正文返回冲突；超时不能换键重新执行。

新研究以版本化 `ResearchSpecification` 记录短名称、问题、经济依据、明确评价指标／阈值、搜索成员界限、停止规则和可选资金假设；共享验证器拒绝未支持的覆写。宿主与研究工具从原合同呈现指令，失败／越界试验仍计数；确定性投影从原分区指标区分计算、达标、未达标、证据不足和失败。旧 goal-only 输入和原始重放身份不改写。

十进制、超出 JS 安全整数范围的计数与纳秒不能先转 `Number`。正式指标拒绝 NaN／Infinity，未知值保持 null，缺口不补零。计算成功、研究完成、独立证据和下游 ACK 是不同事实。

<a id="pm-platform"></a>
## 自动量化 PM 业务

PM 是既有研究与共享账户科学计算的业务消费者。所有者提供目标、登记数据、资金来源、模型和总试验预算，并可明确收益优先、下行优先或保留 Pareto 权衡；系统记录 `MandateRevision`、冻结 `DecisionPolicyRevision`，产生研究、训练组合与账户配置证据。使用方案和验收边界见[实现任务](tasks/pm-adaptive-platform/task.md)及[评审合同](tasks/quant-pipeline-integrity/design/contracts.md)。当前运行时 DTO 与校验以 [pm.ts](../packages/contracts/src/pm.ts)、[pm-validation.ts](../packages/contracts/src/pm-validation.ts) 为入口；`ResearchTrial.id` 是业务字符串，原数字 Task ID 只在 `runtime` 中保存。

[所有者边界归一化](../packages/contracts/src/pm-intent.ts)保留原目标的准确引用和版本，不把模型解释直接当执行约束。明确“不要杠杆／No leverage”可形成最大总敞口比例 1、禁止借款的冻结规则；科学执行要求原生 CASH、禁止借款的账户及配置上限，不能用 MARGIN 的 leverage=1 冒充。未知语义保留澄清缺口；所有者通过原请求／修订身份补充说明，已有边界不能隐式删除或放宽，预算和暴露历史继续保留。未来最大回撤愿望不成为可保证的收益路径。

[研究扩展](../apps/research/src/pm-campaign.ts)在原官方 Durable 中记录假设、全部尝试、资源消费、比较及收束。训练拟合和可选择的联合账户试验有不同用途；`candidateTrialIds` 明确选择集合，训练尝试继续可见但不冒充账户候选。相同比较范围要求原数据修订、评价协议、角色、实际区间、日历、资金、费用及起始状态相容。试验成功或研究候选胜出不等于新组合已获得独立评价、经济容量或投资资格。

[共享决策方法](../packages/contracts/src/decision.ts)按不可变 `MetricDefinition.id` 与原定义读取证据。原生 Validation 投影仅接受明确分区，排除独立评价和组合中的单成员诊断；252／365 日 Sharpe 精确区分。原生负号回撤转换成有版本的正损失，费用保留十进制与币种，缺失／冲突／晚到数据不补零。负收益日比例覆盖全部完整日，包含现金日，缺日不能得到完整日绩效。经验 Pareto 前沿是点估计描述，不是显著性结论；诊断前沿不能改写冻结的目标排序，未解权衡保留多个候选。

独立指标通过单独的 `projectNativeIndependentMetrics` 读取原 HELDOUT 分区，角色固定为 `INDEPENDENT`，不能重新标成 Validation 或返回研究选择反馈。所有者通过 [PM 资源路由](../apps/service/src/pm-routes.ts)读取原证据引用与正文、周期、研究账本和历史决策；计算失败也保留原错误证据。[预注册配对经济反证](../apps/service/src/pm-qualification.ts)只检查已冻结配置在独立区间是否按原偏好严格优于同起始状态基准，最高晋级到 SHADOW；不宣称统计显著、实盘资格或因独立失败重新选择。

[原生组合拟合](../apps/job/src/ensemble_fit.rs)只使用训练截止前已经成熟的标签，交叉拟合校准任意分数后，用 Clarabel 计算非负、和为一的组合系数。系数连接的是实际因子模型与原报告，并非虚构可交易因子标的；资产配置与其后的共享账户回放是不同操作。`freeze-ensemble-calibrations` 保留同一模型、校准、截止和来源关系；每次新拟合、联合回放、资金配置测试与现金基准均属于可追踪的科学工作，不因失败免费重试。

[服务 PM 周期](../apps/service/src/pm-platform.ts)由原官方 Task 驱动，捕获 mandate、policy、dataset、account 和 incumbent 的版本依据，旧依据完成的结果仅保留证据，不能覆盖新决策。研究用 `CandidateComparison`；运行配置用 `OperatingComparison`，明确历史联合回放、前瞻模型估计或实际观测，不能伪造 `ResearchTrial` 充当账户配置。已证明的原生硬约束不可行候选可退出偏好排名；进程错误、编译失败和缺指标保留未知，不能当作科学否证或经济不可行。

[历史账户科学适配](../apps/service/src/pm-science.ts)在每个资金部署上限重新执行原生 `study-portfolio` 配置与账户回放，保持所有者完整初始 NAV 和同起始现金状态，余款保留现金；资金点 K 表示初始 NAV 下的配置比例，后续权益按该比例再投资，不冒充整个存续期的绝对名义金额上限。共同现金基准使用同一实际回放区间、费用和币种。[原生资金点计算](../apps/job/src/capital_curve.rs)保留实际测试点和非单调缺口，最大测试本金不是已支持容量，未经验证的区间不插值。资产配置方法的风险厌恶参数来自版本化方法；固定参数不声称由所有者偏好或数据自动学得。缺少冲击、退出与原生参与率证据时，不给出经济容量上界。

既有账户通过[原始账户捕获](../apps/service/src/pm-account.ts)保留完整 `nativeObservation`、明确零未完成订单报告、原生账号与传输别名映射及账户级资金预留；同来源的新序列不能更换真正原生账户。经济状态 `ts_event`、原生发布 `ts_init`、producer heartbeat 与本机首次收到时刻各自保留，后到控制事实和本机预留不能沿用更早可得时刻。缺少原生余额、显式订单数量、连续性或真实接收时间时不从单一权益反推持仓／现金。

[账户控制来源](../apps/service/src/capital-exit.ts)按原 URL、环境、client/account 连接保留能力正文与首次接收时间，相同正文重读不续期；真实账户控制版本、预留与退出责任仍由物理账户共享。某别名只读、不可读或 GET 失败不改写其他连接的权限与已知物理状态，真实来源的账户封锁则约束所有别名。既有[账户刷新](../apps/service/src/workbench.ts)实际读取账户、能力与资本控制，先履行原不确定回执核对；没有原回执的账户来源无需虚构旧组合。当前读取失败明确保留未知及原错误时间，不把当前接收事实回填历史研究；历史研究使用其准入时冻结的起始账户证据。

[既有现货科学适配](../apps/service/src/pm-account-native.ts)调用 `value-observed-spot`、`compare-observed-spot` 和 `study-observed-spot`。只接受已证明无锁定、借款和在途委托的多币 CASH 状态及原生支持的显式现货政策；相同原始数量分别进入零主动订单的 HOLD 和重新配置回放。原生价格按账户经济时点估值，派生 report NAV 位于独立 `AccountBasis.valuation` 并保留原证据、方法、时点和可得时间，不回写原 source equity。PM 数据摘要与 native UUID 使用持久桥接证据，恢复不生成另一映射。每个 HOLD 和 REBALANCE 均消耗科学尝试，原约束不可行时保留原 solver frames 和已完成基准；历史对照不当作真实账户收益或未来预测。现金现货每日证据读取原 `spot_cash_report`，不能把预测分数或未覆盖整日的路径当每日收益。

完整计算后的候选若按冻结全部目标仍精确并列，保留未决比较、派生估值和原生证据，不强选赢家或触发新独立晋级。ACCOUNT 服务验收用明确已收到的归档软件来源事实，独立读取原报告核对指标、共同初态与零主动订单的 HOLD，并证明今天首次接收的旧快照不能进入过去的决策；这不建立券商来源或真实市场 PIT 资格。

[当前冻结方法消费者](../apps/service/src/pm-forward.ts)通过 `build-observed-spot` 对原账户数量、决策截点前的价格及同一已冻结模型进行一次前向计算。`AccountBasis.valuation.timeBasis=DECISION_CUTOFF` 明确按当前标记重估，原 snapshot 经济时点和数量不改；输入最大实际可得时间与派生报告生成时间分别保存。`OperatingComparison.modeledComparison` 使用原标签期限的预期收益、方差、线性成本和事前登记的方法目标，不消费历史每日收益／回撤排名，也不把固定风险厌恶参数解释为学习出的所有者效用。原生连续解、手数取整后的数量和成本分开保留，运营比较使用取整后模型；不可执行的模型建议仍保留解释，不能重新投影为可选目标。固定方法的一次运营应用不增加研究试验，改变方法或参数需要回研究阶段。

[执行源边界合同](../packages/contracts/src/pm-forward.ts)校验原 transport `execution.pmEvidence` 的账户／序列／控制版本、真实接收时间、环境、完整费用分量、净换仓入口额度和完整目标退出额度；BAR 成交金额不替代可执行容量。任何未知冲击成本、完整原库存缺失或币种冲突都保留缺证据。该合同的 `READY` 只表示 `CURRENT_SOURCE_EXECUTION_BOUNDS`，不替代数据 PIT、独立方法评价、原生价格／手数规则或下游原子版本封套。目标期限来自原 cutoff 加冻结 TTL，并受更早来源有效期约束，不能按重试时间续期。

历史配置输出中的目标金额是明确初始 NAV 下的情景表达，不是当前持仓或当前账户换仓额；无对应持仓事实时 `currentNotional` 和 `netTradeNotional` 成对为 null。前向 `AssetTarget.executionEstimate` 单独保留原生按交易单位取整后的预计数量、资金与调整额及证据引用；连续目标字段不被覆盖，预计调整不当作实际成交，且当前金额加预计变化必须精确等于预计结果。资金计划与各策略归属使用精确十进制守恒；不可有限十进制表示的派生资本比例可为 null，真钱金额仍精确守恒。正式目标交付还要求权威账户依据、当前资格及已知差额。PM 目标消费者已接入资格核验、原回执交付与对账，ACK 不当作成交；历史成功或 SHADOW 不自动产生已获资格的当前账户决策，也不自动续期或授权下游交易。研究、配置、独立评价、目标交付、成交观测和退出责任分别保留。

[账户事件适配](../apps/service/src/pm-account-events.ts)只读取受信传输的显式区间、完整性声明、原现金流和成交 ID；缺失来源与来源确认的空区间不同。金额、币种、未知手续费及 source／receiver 时钟保留，重复原事件只记一次，同 ID 改正文拒绝。后续账户现金流调整权益差必须具备完整覆盖与同币种，不自动称作策略 PnL 或 TWR。退休还检查原多币余额与零在途订单，不能因为归一化 positions 为空就宣布没有敞口。

Web 的 PM 工作区与 `quazonai pm` 读取同一服务事实，展示自动组合、比较、资本点、证据缺口和历史。版本化请求、未知响应核对、预算与暴露账本沿用原协议；浏览器关闭不会形成第二个调度器。受控协议验收、真实原生科学验收及实际部署运行证据分别记录，不以其中一种冒充另外两种。

<a id="codex"></a>
## 原生 Agent 与无人值守

启动重开原 durable 存储，恢复已提交的原 Task，并按原 request 事实修复 admission 与 submit 之间的缺口。模型超时、SDK／持久重试、压缩、进度写入和工具轮执行方式使用公共 Harness 设置，不导入内部调度器。1.1.0 的 sequential／parallel 是工具轮配置，不是跨会话的全局并发上限。

未完成研究的继续／停止由研究 Extension 在原预算、试验和停止条件下记录；失败试验不能变成免费重算。安全计算可按原任务重放，外部副作用结果未知时必须先对账。关闭宿主暂停原工作，不能把本地退出写成远端取消。观察者断开不取消研究；显式停止核对原生终态。原 owner stop 的未选取 `STOPPED/owner_stop` 事实仅在前驱实际成为 `unanswered/aborted` 且原预算有余时，允许既有显式续作入口接续同一 Conversation；保留完整 `previousStops`，不重开旧提交，admission 缺口沿原身份修复。活动、已选取／评估、耗尽或无关失败不接续。

Provider 与模型来自实际配置的官方目录，无静默模型回退。凭据留在明确配置的宿主存储／环境，既不进入研究输入，也不传给科学子进程。模型质量、真实账户结果和全天候运行的实际观察时间必须单独披露，短协议测试不作替代。

原 `ResearchInput` 的可选 `publicLiteratureQueries` 保存所有者填写的 1–3 条公开检索主题，每条最多 500 字符且不含控制字符；原始输入和 dataset 简写请求均支持。研究 Extension 的 `research_literature_search` 只接收模型选择的 `queryIndex`，可信工具从冻结的所有者列表取实际查询，经 Crossref、arXiv 和 Semantic Scholar 的公开 API 检索元数据与可用摘要。模型不能提交任意查询，也不从 goal、正文或 specification 自动提词；系统不判断所有者填写的文本是否敏感。未配置时返回 `public_queries_not_configured` 和空来源列表，表示能力未配置而非来源失败，不阻断科学研究。旧研究和旧文献回执保持可读，无配置不能发起新的外部检索。

`research_literature_note` 将支持／反对／背景论点、适用限制和摘要摘录绑定已保存论文，`research_literature` 只读取原结果。独立 `qz.literature` 事实文档存于同一官方 Durable 存储，保留原 Task、来源回执和失败；已提交检索结果的重放、关闭重开及重复读取复用原事实。文献状态与科学试验账本分开，引用不改变数据准入、试验预算、Sealed 隔离或独立评价结果。公开 API 不等于全文访问；无摘要、限流及部分来源失败保持明确状态，不能由模型补写原文。

同一规范化查询默认复用最新保存回执。最新结果为 `partial`／`unavailable` 时，可由新 Task 显式传入 `retryFailed:true` 重试并追加新回执，保留此前失败；原 Task 重放仍返回自己的原回执。成功及成功空结果不因重试标志、修改条数或重复查看而重新检索。

## 数据与独立评价

数据来源通过独立于 Pi Durable 的 [DataSourcePlugin](../apps/service/data-sources.md) 加载，统一出现在扩展目录的 `kind: data` 中，在设置的「数据插件」页保存配置、启停与手动加载。内置来源兼容 `service.json.datasets` 并支持现有工具导出的 DatasetConfig 文件；外部模块返回同一数据合同。每源配置、最近成功结果和既有任务所需的历史数据源配置原子写入 `data-sources.json`，加载失败保留已有结果，禁用仅移除新准入可选数据而不删除目录和历史。禁用或刷新省略原数据集后，已有投资决策仍通过保留配置监视原来源，重启后恢复；真实来源读取失败仍按原逻辑处理。启动恢复成功结果，不自动下载。数据集 ID 在历史中保留原来源归属，原来源可以更新，其他来源不能重用并重定向既有决策；新准入绑定当前回测实例，已捕获研究输入保持原样。

保留原数据目录、Instrument 定义、Universe 历史、来源、许可、质量、可得时间和研究版本。`event_at`、`available_at`、`decision_at` 不可互换；PIT 要求 `available_at <= decision_at`。抓取成功、当前成分或重述后的数值不冒充历史可得。

[公开行情准备](../runtimes/data/hyperliquid.md)按声明式文件/字段映射导入来源中全部市场的 BAR、逐笔、盘口快照与资金费率观测；下载和转换不按交易所或币种分支。合约与历史标识解析复用官方适配器，不用标识补造合约参数。币种原生属性随目录保留，通用读入/分区准备恢复它们。可选官方高精度格式保留十位小数，既有目录及默认科学构建不变；新格式消费者必须使用同一精度构建。原始文件与许可留在操作边界；当前参数、事件时间代理、快照盘口和本地读回不建立历史覆盖、PIT 或永续资金费结算能力。缺失映射或拒绝行产生不完整报告和失败退出；可确定标识但历史定义缺失则单独计数。科学入口保留 BAR 合同，并支持显式 TradeTick 单因子探索。

全历史逐笔探索可显式选择 `EVENT_TIME_COHORT_CACHE_V1` 派生表示，复用原生数值转换和精确同时间归约，不冒充原生 TradeTick 目录。固定 32 字节帧保存派生统计标记和笔数；原七特征 ABI 不变，流式评价保留跨文件状态、标签和全局 fuel，并以在线 pooled covariance 汇总。主研究与独立视图只读各自声明的字节范围，导出配置绑定来源发布器持有的不可变副本；同源别名在新发布副本内部共享文件。标签同时支持旧 `FIXED_TRADE_COHORTS` 与显式 `FIXED_EVENT_TIME` 纳秒期限：使用同品种首个事件时间达到 `t+horizon_ns` 的完整成交组，实际跨度可能更长；第二单调 reader 保持标签内存常量，不向特征泄露未来。该路径不提供固定决策时钟、延迟模拟、微观结构执行、tick 组合或科学资格。

受信任来源可通过配置 `revisionManifest` 发布不可变文件修订。[来源消费者](../apps/service/src/pm-source.ts)核对实际文件字节／SHA-256、全部目录覆盖、来源可得时间及包含修订性质的清单摘要，拒绝未登记文件、路径越界与符号链接别名。[修订准入](../apps/service/src/pm-datasets.ts)保存原清单快照和修订关系，同一来源修订不得改正文，后续修订不得复用或覆盖任何已准入历史目录。APPEND、CORRECTION、RETRACTION 触发各自版本事实；静态旧来源不补造清单或文件不可变资格。该消费者验证文件输入与时钟约束，来源接收时钟的 PIT 品质和实际市场覆盖仍需独立证据。

Discovery／Validation／Sealed／Forward 的原用途与暴露账本保持隔离。研究员不能读 Sealed，最终评价不反馈模型继续调参；复制目录、改标签或重启不能重置暴露与预算。失败、取消、无效及已比较试验继续留在账本。缺数据、来源不合格或原生接口不支持时保留具体失败，不生成假指标或假资格。

<a id="runtime"></a>
## 科学执行

TypeScript 适配层只执行已登记的原生科学操作，捕获原输入、模型、政策、期限与原 Task 身份。执行和清理优先复用官方 NodeExecutionEnv／Task 子任务能力；不接受模型指定任意宿主命令。输出必须对应原请求，进程 exit 0 或文件存在不等于证据通过。

Rust 仅保留必要计算与原生引擎接口。Wasm 使用有限燃料、内存和时间。数据获取、原生目录准备及许可证边界见[数据指南](../runtimes/data/README.md)和[来源插件](../runtimes/data/source-plugins.md)。

## 策略组合与曲线

任意因子分数不是收益预测或仓位；转成策略必须使用显式的原政策和来源适配，不能默认归一化后冒充目标。组合绑定原研究／试验、模型、费用、币种、共同期限、资金和市场输入。Clarabel 无解不返回备用权重，未知持仓不按资产清单猜测。

原子因子以 `r<research>.t<trial>.m<member>` 绑定原研究／试验／模型，不另建因子状态数据库。组合成员的诊断不冒充单因子独立证据；新组合保存明确原子引用和精确权重，旧 research-ID 请求仍可重放。

`assess-capacity` 使用各原决策前可得 BAR 的原生名义量、显式参与率、净目标变化、建仓／全量退出假设和原生最小订单，取最紧标的约束；场景资金和最小实用本金由 Rust 精确计算。报告是条件历史可行性，不是未来盘口、冲击模型或收益保证。组合净需求共享同一流动性预算，不加总单因子容量。因子可在研究完成后通过 `POST /factors/:id/capacity` 明确提供共享 `CapitalAssumptions`；只重用原模型／执行映射作只读容量计算，不改 admission、试验或独立证据。新组合的独立 `capacityPolicy` 决定联合评估，不要求成员研究预先声明相同情景。

回测权益来自 Nautilus 的同一个共享资金账户。不能加总单 Alpha 曲线、拼接独立本金的验证折曲线或重复扣费。图表是原生权益的显示投影，不生成第二份权威净值。官方 0.63.0 不支持的合约定义原位更新仍明确拒绝，保留原始规格历史和稳定窗口能力。

`catalog_ensemble_request` 通过[原生目录组合入口](../apps/job/src/catalog_ensemble.rs)扫描原目录全部已观测市场；成员共用因果特征流，正分数按原政策动态分配同一账户资金，不预选市场或均分固定市场预算。原来源费用归档逐时段流式读入，跨时段待成交订单继续绑定其原 BAR 的数量和费用池。Validation 与最终评价分别从原分界启动全新账户，分界前仅预热模型；最终每日收益原序列只投影给所有者。

此入口的成交方向／费用特征来自原始逐笔记录，缺失值保留掩码。缺少原盘口、接收时钟及历史交易规则时，显式使用长仓、1 倍保证金的 pUSD 代理场景，并输出延迟、BAR 成交及费用适用性假设；它不建立真实盘口套利或交易所现金账户资格。独立评价的暴露规则保持不变，目录场景的容量和可交付目标在没有原生支持时保持不可用。

<a id="handoff"></a>
## 目标与观测

目标包、下游身份、原回执、到期、Claim／ACK／撤销互不混淆。同一外部身份重放原结果，不刷新期限。未知提交结果先核对，不能另发一份目标或推断撤单。实盘／模拟盘页面读取所绑定的真实账户来源、会话、序列、时间和权益／持仓；未连接和缺指标保持未知，测试输入不改标 REAL。

显式开启净值自动调整后，官方 Durable 任务连续读取权威快照，以原选池和原权重调用 `size-account`：先扣账户级未完成资金预留与现金缓冲，再以联合容量、当前持仓差额、流动性、费用和订单增量限制资金。源目标／容量到期不续期；执行能力或账户来源／控制修订未匹配时仅投影或阻止，不交付。每次有效调整保存快照／控制修订／原子池／容量依据与独立回执身份；不确定 POST 仅核对原回执。

资金退出使用可选、能力声明的原生 V1 下游桥接，不再实现所有者或券商引擎。原生 Request／Preview／Start／Action／View 通过科学合同检查，预留与命令 admission 同事务保存；未知命令不重发 POST，接受回执不等于状态已完成。暂停／取消仍保留原生预留，外部提取仅提交证据对账。能力缺失时禁用发起，但显示已提供的账户级预留／进度；未知预留阻止新目标交付；新手动目标在首次绑定或发现别名时也必须重新读取权威资金状态，不依赖缓存零值。具体路径、修订绑定与原生 owner 责任见[账户传输合同](../apps/service/account-transport.md)。

## 市场适配

Polymarket 等来源复用官方 Nautilus 适配器及原目录。历史费率、许可、PIT、交易截止与结算证据保留；当前 API 状态、最后价格或链上取回时间不能代替原可得性和结算事实。科学成功不授权实盘执行。

## 界面与交付

浏览器、CLI 与 Skill 操作同一服务。界面以研究为主，原子因子库、组合回测、目标与观测和设置为独立入口；设置内含模型设置、数据、数据插件、扩展和实例连接；旧数据与扩展地址继续进入对应设置页。使用中性纸面／深色石墨主题、顶部导航和单一工作文档。原始输入、失败试验、独立证据、精确数值与回执／账户事实分别呈现，移动端不丢操作。页面不以 202、缓存或未知终态显示成功。

投资决策、研究、原子因子和组合支持持久化逻辑删除，Web 与 CLI 共用无正文 DELETE 及原 `{kind,id,deletedAt}` 回执；重试保留原删除时间。常规列表／详情和新消费者隐藏已删对象，原研究输入、试验／暴露账本、冻结组合证据、目标与账户回执仍保留，不能借删除重置预算或恢复同一请求。活动任务与仍在使用的依赖明确拒绝；研究删除同步隐藏派生因子，单因子删除不改试验。投资决策须先退休并完成外部责任对账，删除不代表远端取消或平仓。研究 owner 命令与删除共用串行边界，组合／观测最终准入在同事务重验删除事实。

新研究表单提供可选的公开论文检索主题，逐行填写并随原请求冻结，不另加确认步骤。研究详情的文献标签投影原 `qz.literature` 事实，展示来源、论文链接、可用摘要、主张关系、限制和检索失败。未配置公开主题、尚未检索、成功空结果和服务不可用分别呈现。界面读取不触发新的搜索，论文与 Agent 笔记的来源身份保持可区分。

非敏感草稿和待核对命令保留在当前浏览器标签页；未知提交重放原始请求，不生成新身份；迟到响应不能清除较新的命令。已确认身份冲突须显式结束核对，保留原提交供下载，再由用户发起新提交。模型密钥、密码和实例令牌不进入浏览器持久草稿。实例配置通过所有者认证的 `/api/v3/settings/instances` 读取与版本化 PUT 保存，原子写入现有数据目录的私有 `instances.json` 并在启动时恢复。回测／研究与各模拟盘／实盘连接分别配置，直接填写令牌，界面使用密码输入遮盖；旧环境引用保持兼容。秘密仅存在私有配置及传输授权中，研究与科学输入保留凭据引用；新准入使用新绑定，旧研究、PM 与观测继续保留原连接。并发冲突和保存失败不显示成功，未知响应按原配置核对。设置采用显式保存，既有账户保持手动刷新；新增净值自动调整须显式开启，并由 Durable 而非浏览器轮询执行；本地停止不代表下游撤回。执行错误只投影公开错误码，原诊断保留在 Durable；观测状态不替代快照事实，权益图按实际时间间隔绘制。组件与恢复行为见[研究工作台设计](tasks/research-experience/spec.md)，浏览器检查包含临时真实 HTTP 服务，科学证据仍由原生核心检查负责。

应用镜像携带官方 Node、TypeScript 服务／CLI、Web 和匹配科学入口。官方 durable 调度在单一应用所有者中运行，不再提取 Rust Worker。容器重启恢复原数据目录；备份在写入者停止后进行。升级保留安装身份、配置、凭据、数据库、产物、journal 和备份，无法接续的旧活动必须明确拒绝升级而非清零。

实际命令与验证见[项目入口](project.md#commands)，运行和恢复见[operations](operations.md)，安装包见[部署手册](../deploy/docker/README.md)。
