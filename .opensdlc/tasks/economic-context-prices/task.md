# Explicit oracle and mark observations for economic replay

A held perpetual can have no trade for hours while public oracle and mark observations remain available. Using its old trade for funding made the first missing valuation poison the remaining account path. Keep price features and execution based on the retained trade cohorts; use a separate optional economic source for funding notional and perpetual PnL/NAV.

The optional native/TS request field is `context_source: "context-prices.manifest.json"`. Omission retains legacy behavior and serialization. The independent fundingCatalog remains the owned economic binding, including recovery of the original receipt. No third catalog root or research-input/feature change is introduced.

The manifest declares schema 1, EVENT_TIME_CONTEXT_PRICE_CSV_V1, EVENT_TIME_PROXY_UNVERIFIED, independent source_revision, original research_source_revision, requested start/end, string rows and per-instrument file counters/clocks. Sorted instrument_ids map to flat context-prices-000.csv files. CSV is event_ns,oracle_px,mark_px with exact decimal/scientific strings; blank fields remain unknown. Readers are bounded, strictly ordered and use the last observation at or before economic time under the existing maximum_mark_age_ns. Funding uses oracle and actual rate settlement time. Perpetual NAV and its scheduling capital base use context mark; trade Asset.mark, execution price/capacity, spot/FX and model features remain unchanged. Explicit context has no trade fallback. Unknown funding remains irreversible; gaps and missing NAV remain visible.

Preparation extends the existing economic_sources list and hardlinks the same source into primary and independent views; export validates the manifest and files before the existing owned snapshot copy. Existing logical output budgeting remains intact; full new preparation uses the existing --maximum-output-bytes 68719476736 (64 GiB) option.

Validation reuses existing native economic/parser/ledger/preparation tests and TS contract/API/export suites, including scientific notation, causal age, empty fields, duplicate clocks, oracle/mark separation, stale trade isolation, original request serialization, recovery and source identity. The normalized actual context source is separate operational work: 119,131,986 observations, 206 CSV files, 4,244,852,464 bytes, with recorded gaps. These observation clocks do not establish historical availability or complete coverage. No economic replay admission, real order, service update or live catalog mutation is part of this code delivery.
