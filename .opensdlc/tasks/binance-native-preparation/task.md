# Prepare supplied spot archives through the installed source lifecycle

## Requirement and scope

The existing [offline archive stage](../binance-vision-spot-archive/task.md) can
freeze and verify supplied Binance spot files but cannot complete the installed
native preparation path. Add that path to the existing pluggable source registry
and two operator executables. No downloader, finance-account operation, terms
acceptance, real-source fixture, implicit registration or research qualification
is part of this batch.

The native profile is deliberately limited to ordinary single-member
stored/deflate ZIP. Unsupported ZIP64, multi-disk, encryption and other unsupported
container forms reject. An independent review of a bounded public-API proof
approved this profile rather than expanding a ZIP compatibility framework. Its
123 synthetic cases were feasibility evidence only, not production acceptance.

## Implementation boundaries

- Preserve `qz.public_archive_acquisition/1`, standalone Python flags, original
  raw ZIP/checksum, normalized decimal lexemes, source clocks, file identities
  and conservative admission. Keep legacy HTTP source descriptors unchanged.
- Add `catalog-prepare ingest-archive-candles --acquisition ... --instruments ...
  --output ...`. Original native definitions are mandatory. Share candle
  numerical conversion, definition checks, native serialization/readback and
  publication with the existing Coinbase path; do not duplicate that kernel.
- Use official public typed ZIP parsers and an independent decompression budget.
  Fully consume the declared central range, reject hidden members and clipped
  rows, and verify original sizes/CRC. Reproduce the complete manifest and CSV
  lineage independently before native publication. No private APIs or copied
  upstream parser.
- Preserve all twelve CSV fields, decimal precision, ms/us source units, sparse
  buckets and nanosecond chronology. Reject duplicate JSON fields, malformed
  records, changed originals, lossy native numbers, foreign/future definitions
  and ambiguous definition/receipt ties.
- Require explicit archive retrieval completion. `UNKNOWN` and missing receipt
  clocks reject. Original null observed/historical-availability fields remain
  null in evidence; declared initialization is labelled
  `OPERATOR_DECLARED_UNVERIFIED` or `SYNTHETIC`, never attested. Import/publication
  time is not substituted. Existing microsecond metadata constraints remain.
- Register offline plan/inspect/freeze/verify/convert/prepare capabilities and a
  per-plugin native-publication validator. Shared preparation dispatches through
  the registry. Installed freeze has the same new-output/mount requirements as
  other writing operations and cannot receive network access.
- Include the Python module in the existing image. Retain both native binary
  names, literal argv execution, pinned image identity, reserved-path refusal,
  local-host handoff and unchanged default scientific image behavior.

## Verification and cost gates

Run all source tests, original Coinbase native regressions, new archive native
tests and binary unit tests, both-feature all-target Clippy, default native graph
comparison, formatting, docs/installation checks and all applicable CI. The
history workflow explicitly executes the new targets. The actual installed
smoke adds original synthetic ZIP -> installed freeze -> verify -> native convert
-> prepare, preserving original bytes, exact metadata digest/host paths, source
receipt basis, fixture/non-PIT status, original processor identity and refusal to
reuse output. The cold registry installer executes the same path; host compilation
and package installation remain forbidden during that acceptance.

Record the actual feature lockfile delta, dependencies/licenses, stripped native
ELF bytes and application image/archive cost using the existing measurement
pipeline. No speedup claim follows from a source-code prototype or warm build.
The first native test-link attempt was interrupted before exhausting the local
executor disk; its unexecuted tests require hosted acceptance, not a waived gate.

Local validation executed 125 source tests, 21 installed-source contract tests
and 12 installer shell tests successfully. Of 150 deployment tests, 149 passed;
one existing AF_UNIX test is blocked by the executor socket restriction and stays
enabled in hosted CI. Native binary/integration-target checks passed on an earlier
candidate, before final test additions and canonical JSONL ordering changes.
Final native compilation/execution, Clippy, image cost and cold-install proof
remain pending. The review/PR must retain this distinction and record the final
source identity and actual hosted outcomes rather than treating this plan as
completion.

## Delivery and limits

Independent native review and all final-head checks precede dev merge. Follow
the merged source through postmerge release and fresh install acceptance.
Applicable upstream rights, real acquisition, original historical fees and
definitions, source/grant registration, frozen InputSets and fresh
`DATA_VALIDATE` remain separate requirements. Deterministic fixtures do not
qualify either real market data or an Agent model. This batch neither uses nor
changes the paused operator single-binary experiment.
