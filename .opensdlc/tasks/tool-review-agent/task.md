# Evidence-bound quantitative review agent

Issue: [#270](https://github.com/zhengui666/QuaZonai/issues/270).

## Goal

Upgrade factor, portfolio and allocation review on remote `dev` (base `837beda8`). Use isolated official Pi Durable conversations, trusted native scientific tools, deterministic scoring and immutable reports. Review may admit candidates and propose weights; original independent evidence and target delivery conditions remain required.

## Implementation

- Native diagnostics: signed rank IC, dependent-sample intervals, quantile diagnostics, selection-bias analysis and paired portfolio comparisons. Unknown evidence remains explicit.
- Frozen versioned policy: non-compensable integrity checks, six dimensions, 80-point admission, 65-point rejection boundary, 60-point statistical/robustness/execution floors and prior reference calibration.
- Quality-aware nonnegative QP allocations use official Clarabel, fixed diagonal shrinkage, original member/cluster/turnover limits and immutable candidate provenance. No result is deployable without its own shared-account study and independent review.
- Review artifacts are available through owner-authenticated API and the existing research, factor and portfolio views, with JSON/Markdown export.

## Research basis

[DSR](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf), [PBO/CSCV](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf), [Alphalens](https://alphalens.ml4trading.io/api-reference.html), [AlphaAgent](https://arxiv.org/html/2502.16789v1), [RD-Agent](https://rdagent.readthedocs.io/en/latest/scens/quant_agent_fin.html) and [net trading costs](https://www.aqr.com/Insights/Research/Working-Paper/Trading-Costs-of-Asset-Pricing-Anomalies). DSR/PBO diagnose the search process, not future profitability. Complete comparable trial histories and valid time isolation are necessary inputs.
